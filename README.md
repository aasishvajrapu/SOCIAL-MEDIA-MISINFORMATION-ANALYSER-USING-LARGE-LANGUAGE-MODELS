# Social Media Misinformation Analyzer using Large Language Models

## Overview
This project uses Machine Learning and Large Language Models (LLMs) to analyze social media content and detect misinformation.

## Features
- Fake news detection
- NLP-based text preprocessing
- BERT/LLM-based analysis
- OCR support
- Dataset cleaning and evaluation
- Accuracy and confusion matrix visualization

## Technologies Used
- Python
- Flask
- Transformers
- BERT
- Pandas
- Scikit-learn
- HTML/CSS/JavaScript

## Project Structure
- app.py → Main Flask application
- analyzer.py → Content analysis
- preprocess.py → Data preprocessing
- bert_model.py → BERT model logic
- evaluation.py → Model evaluation
- templates/ → Frontend templates
- static/ → CSS/JS/assets

## Future Enhancements
- Real-time social media analysis
- Multi-language misinformation detection
- Improved AI model accuracy
